# Código de conducta

Adoptamos el [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Resumen práctico

- **Sé respetuoso.** Critica el código, no a la persona.
- **Asume buena fe.** La gente tiene contextos distintos.
- **Acepta el feedback.** Si tu PR recibe comentarios, no es un ataque personal.
- **No toleramos:** acoso, discriminación por cualquier motivo, lenguaje sexual o violento, doxxing, troleo sostenido.

## Aplicación

Reportes a **nando.sr@gmail.com**. Confidencialidad garantizada para quien reporta. Las acciones pueden ir desde un aviso privado hasta el ban permanente del proyecto, según gravedad.

## Alcance

Este código aplica a todos los espacios del proyecto: issues, PRs, discusiones, código, commits, y cualquier comunicación pública o privada relacionada.
